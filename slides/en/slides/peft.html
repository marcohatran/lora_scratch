from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=8, lora_alpha=16, lora_dropout=0.05,
    target_modules=["c_attn"],
    fan_in_fan_out=True,   # GPT-2 Conv1D
    task_type="CAUSAL_LM",
)
model = get_peft_model(model, config)
model.print_trainable_parameters()
# trainable params: 147,456 || trainable%: 0.1797

model.save_pretrained("zorblax_adapter")
merged = model.merge_and_unload()

Now that you know what is inside, peft is a thin, well-tested wrapper around the same idea. fan_in_fan_out tells it GPT-2 stores weights transposed, which is our transposed flag. In real projects you would add transformers Trainer or TRL’s SFTTrainer for the training loop.
