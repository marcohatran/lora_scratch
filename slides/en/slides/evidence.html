02 · How LoRA works

The rank must cover the real change

Toy test: a 128 × 128 “pre-trained” layer must learn a change ΔW of rank 4. Same data, 1,500 Adam steps.

r below 4 underfits. r = 4 matches full fine-tuning with 16× fewer trainable parameters.

MethodTrainable paramsFinal loss
Full fine-tuning16,3846.7e-9
LoRA r = 12562.1e-2
LoRA r = 25121.2e-2
LoRA r = 41,0249.3e-8
LoRA r = 82,0481.2e-6
This experiment has a known answer, so we can see the mechanism directly. With r of 1 or 2 the loss stalls around one percent; at r equals 4 it drops to near zero like full fine-tuning. In real models we don’t know the true rank, so r is a hyperparameter.
