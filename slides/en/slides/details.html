02 · How LoRA works

Three details that make it work

B = 0

Start from the original

At step 0, BA = 0, so the model is exactly the pre-trained one. A is random so gradients can flow; if both were 0, nothing would ever learn.

× α / r

Keep the scale stable

Dividing by r keeps the update’s size steady when you change r, so the learning rate does not need re-tuning. Common: α = r or 2r.

W′ = W₀ + ΔW

Merge after training

W′ has the same shape as W₀, so inference is exactly as fast as the base model. Or keep A and B separate as a swappable adapter.

Zero-init of B means training starts at the pre-trained point instead of breaking it on step one. The alpha over r factor is a convenience for tuning. Merging is what makes LoRA free at inference time, unlike adapter methods that add layers.
