03 · Implement LoRA

Inject it into a real model, then train

def inject_lora(model, targets, r=8, alpha=16):
    for p in model.parameters():
        p.requires_grad_(False)      # freeze everything
    for parent in list(model.modules()):
        for name, child in list(parent.named_children()):
            if name in targets:      # swap in LoRA
                setattr(parent, name, LoRALayer(child, r, alpha))

model = AutoModelForCausalLM.from_pretrained("distilgpt2")
inject_lora(model, {"c_attn"})   # GPT-2 attention q, k, v

opt = torch.optim.AdamW([p for p in model.parameters()
                         if p.requires_grad], lr=2e-3)
loss = model(**batch).loss   # labels = -100 on the prompt
loss.backward(); opt.step()

Pick target layers

Here the attention projection c_attn. In practice: all linear layers.

Higher learning rate

1e-4 to 2e-3, about 10× full fine-tuning.

Mask the prompt

Loss only on answer tokens, so the model learns to answer, not to ask.

The injection walks the module tree and replaces every layer with a matching name. That is exactly what target_modules does in peft. The training loop is ordinary PyTorch; the optimizer only receives the parameters that still require gradients, which are A and B.
