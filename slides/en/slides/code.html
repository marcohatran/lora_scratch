03 · Implement LoRA

A LoRA layer in plain PyTorch

class LoRALayer(nn.Module):
    def __init__(self, base, r=8, alpha=16):
        super().__init__()
        self.base = base
        for p in base.parameters():
            p.requires_grad_(False)   # freeze W0
        d_out, d_in = base.weight.shape
        self.scale = alpha / r
        self.A = nn.Parameter(torch.randn(r, d_in) * 0.01)
        self.B = nn.Parameter(torch.zeros(d_out, r)) # B = 0
    def forward(self, x):
        lora = (x @ self.A.T) @ self.B.T  # d → r → d
        return self.base(x) + self.scale * lora
    @torch.no_grad()
    def merge(self):
        self.base.weight += self.scale * self.B @ self.A

Wrap, then freeze

The original layer becomes base; none of its weights train.

Two new matrices

A random and small, B all zeros. Only these train.

Add the branch

base(x) plus the scaled bottleneck output.

Merge for deployment

Fold ΔW into W0 once training is done.

This is the whole mechanism in about fifteen lines. The notebook version adds dropout, an on/off switch, Kaiming init for A, and handles GPT-2’s Conv1D, which stores its weight transposed. The tests there check three things: identical output at init, only A and B trainable, and identical output after merge.
